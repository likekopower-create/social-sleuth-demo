# Social Sleuth — นักสืบโซเชียล

เกมสืบสวนภาษาไทยเพื่อฝึกตรวจสอบข่าวและภัยออนไลน์ ตัวอย่างเล่นจบได้ 1 คดี: น้ำวิเศษรักษาทุกโรค

เล่นบนเว็บไซต์ GitHub Pages ของ repository นี้ กดเริ่มเกมเพื่อเปิดเพลง แล้วใช้ปุ่มสำรวจสี่สีหรือ WASD/ลูกศร ตัวเกมบันทึกความคืบหน้าในเบราว์เซอร์ของผู้เล่นเมื่อได้รับอนุญาต

ภาพ เหตุการณ์ ผู้โพสต์ และข้อมูลบนฟีดเป็นสถานการณ์สมมติสำหรับการเรียนรู้ ไม่มีการโอนเงินจริงหรือแชร์ข้อมูลออกจากเกม เนื้อหาสุขภาพไม่ใช่คำแนะนำการรักษา
